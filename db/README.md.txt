# Harborstone Marine Insurance - MCP Server Project

## Project Overview
This repository contains the MCP (Model Context Protocol) implementation for Harborstone Insurance. It provides safe, scoped LLM access to marine insurance databases without direct SQL access.

## Folder Structure
- `db/`: SQL Schemas and Seed Data for Harborstone Insurance.
- `mcp_server/`: FastMCP Server implementation handling all 8 protocol concerns.
- `agent/`: Integration agent and client scripts.
